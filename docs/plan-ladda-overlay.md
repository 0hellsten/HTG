# Plan: Laddningsöverlägget

1. Använd appens basadress när hästbilden hämtas, så att den fungerar även när appen inte ligger på domänens rot.
2. Visa en diskret reservbild och behåll texten ”Laddar” om GIF-bilden inte går att läsa in.
3. Lägg till GIF-bilden i filerna som sparas för offlinebruk.
4. Bygg webbappen och kontrollera laddningsvyn i webbläsaren på 390×844 och 1440×900.

Väntar på godkännande innan kodändringar.
